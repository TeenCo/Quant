# Financial and Economic Data Source Directory

This is a starting directory of official, primary, and provider sources. It is not a guarantee that each source is free, complete, commercially usable, or point-in-time. Confirm terms, quotas, coverage, timestamp semantics, revisions, and entity mappings before use. Provider feature claims are generally **Grade 5** until independently validated; official primary records are strong evidence of what the agency published, but not automatically of real-time tradability.

## Official economic and macroeconomic data

| Source | Useful material | Access / timing facts | Caveats and research use |
|---|---|---|---|
| [FRED / ALFRED](https://fred.stlouisfed.org/docs/api/fred/) | US and international macro/financial series; release metadata; observations and vintages. | FRED API needs a registered key. Observation calls support real-time periods, vintage dates, and output types including initial-release observations. | Current FRED views may show revised histories; use ALFRED/vintage parameters for point-in-time experiments. Track reference period vs release time and exact transformation. Official API/docs: **Grade 1** for documented service semantics. |
| [BLS Public Data API](https://www.bls.gov/developers/) | CPI, employment, wages, productivity, labor-market and price series. | API v2 offers registered and unregistered access with different limits/features; supports JSON and batch requests. | Check series-specific preliminary/revised footnotes, historical benchmark revisions, release calendars, and data status. The developer page is maintained by BLS; **Grade 1** for API terms stated there. |
| [BEA API and economic accounts](https://www.bea.gov/data) | GDP, personal income/spending, national/international/regional/industry accounts. | API key registration; source website includes release schedules and methodological documentation. | National accounts are revised. Capture release vintages and definitions; do not treat reference-quarter date as availability date. **Grade 1** for official published series and definitions. |
| [World Bank Indicators API](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392-about-the-indicators-api-documentation) | Cross-country economic/development indicators from multiple databases. | V2 API; documentation says no API key is required. | Mostly low-frequency and often revised/estimated; not an intraday predictor. Use as contextual macro or cross-country regime data. **Grade 1** for source metadata; indicator validity varies. |
| [BIS Data Portal](https://data.bis.org/) | Global credit, international banking, debt securities, derivatives, FX, property prices, central-bank data. | Portal supports exploration and export; docs and permitted-use terms are in portal help. | Many indicators aggregate national data and apply BIS estimates/assumptions. Read dataset metadata, breaks, reporting country coverage, and revisions. **Grade 1** for official data descriptions; methodology varies by series. |
| [ECB statistics](https://data.ecb.europa.eu/) | Euro area rates, exchange rates, inflation, yield curves, monetary/financial series. | ECB Data Portal offers data/API resources; reference rates are normally published around 16:00 CET on working days. | ECB explicitly says reference rates are for information and transaction use is discouraged. They are not executable FX quotes. **Grade 1** for official reference series and stated publication semantics. |
| [Bank of England Database](https://www.bankofengland.co.uk/boeapps/database/) | UK interest/exchange rates, banking, money/credit, financial statistics. | Searchable series database with export and XML change subscription. | Read the series notes, revisions, units, seasonality, and discontinued-series status. **Grade 1** for official UK publication. |
| [EIA Open Data](https://www.eia.gov/opendata/) | Energy production, inventories, flows, prices, electricity demand/generation, projections. | API key registration; API v2, add-ons, documentation, and bulk downloads. Bulk files update twice daily per current page. | Release time, preliminary/final status, surveys, geographic/commodity definitions, and revisions are material. Some datasets are forecasts, not observations. **Grade 1** for source documentation. |
| [NOAA NCEI Climate Data Online API](https://www.ncei.noaa.gov/cdo-web/webservices/v2) | Station weather/climate measurements and metadata. | Token required; docs state a token limit of 5 requests/sec and 10,000/day; data requests have date and page limits. | Weather station changes, measurement quality, reporting delay, station representativeness, unit conversion, and revisions need handling. **Grade 1** for API documentation; station-level quality varies. |

## Regulatory and market-structure data

| Source | Useful material | Access / timing facts | Caveats and research use |
|---|---|---|---|
| [SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) | Filer submission histories and XBRL company facts/concepts. | `data.sec.gov` APIs do not require keys; submissions update in real time as filings are disseminated. Bulk company-facts and submissions ZIPs republished nightly. | Filing dissemination time matters. XBRL facts can have amended filings, custom tags, fiscal periods, contexts, and restatements. Frames are calendar-aligned/latest-filed and may mix nonmatching fiscal periods. Use original filing accession + acceptance time for point-in-time features. **Grade 1** for regulator source and API descriptions. |
| [CFTC Commitments of Traders](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm) | Weekly futures/options positioning by trader category. | Data are Tuesday open-interest snapshots, usually released Friday at 3:30pm ET. Public reporting environment provides filtering/downloads; history depth depends on report type. | Positions are aggregated and trader categories are purpose-based, not direct intent. Low reporting counts can suppress details; contracts may appear/disappear below reporting thresholds. CFTC says historical data is not backdated once published; release lag is essential. **Grade 1** for report definitions. |
| [FINRA TRACE historic data](https://www.finra.org/filing-reporting/trace/historic-data-information) | Corporate, agency, Treasury and securitized bond transactions. | Public bond activity exists; enhanced historic transaction data require FINRA agreement/fees and are delayed (6 months for corporate/agency/Treasury; 18 months for securitized products). Academic corporate TRACE data are restricted to higher-education institutions and 36-month delayed. | Data fields/identifiers and anonymization differ by product. Entitlements and permitted use need to be confirmed; academic files are not a general public feed. **Grade 1** for current published access terms. |
| [FINRA equity short interest](https://www.finra.org/finra-data/browse-catalog/equity-short-interest) | Twice-monthly reported short positions across listed and OTC equity securities. | Reported positions are based on designated settlement dates; reporting due by 6pm ET on second business day; publication generally on seventh business day. Five rolling years online/API. | Not daily short flow, not the same as short-sale volume, and reporting is lagged. FINRA says only the most recent corrected data are made available, so historical correction vintages are not preserved there. **Grade 1** for stated methodology/schedule. |
| [Nasdaq Trader daily files](https://www.nasdaqtrader.com/Trader.aspx?id=DailyMarketFiles) | Annual text/CSV files with consolidated share/dollar volume for Nasdaq securities and selected index closes. | Files organized by year; page distinguishes consolidated activity across venues for Nasdaq securities. | Aggregate statistics, not execution-level data. Check definitions and whether the series corresponds to issue universe vs venue. **Grade 1** for official exchange-issued statistics. |
| [NYSE TAQ historical data](https://www.nyse.com/market-data/historical) | Exchange integrated feeds, order book, BBO, trades, auction imbalance; Daily TAQ across consolidated tape. | Historical/end-of-day products; NYSE advertises delivery EOD/T+1, flat files and cloud availability; many products are commercial/entitlement-based. | Distinguish venue-specific NYSE feeds from consolidated U.S. Daily TAQ. Mapping, sequence, quote conditions, corrections, auction phases, and licensing require product documentation. **Grade 1** for product description, subject to paid access. |
| [CME Group data products](https://www.cmegroup.com/market-data/browse-data.html) | Historical futures/options trades, quotes, market depth and reference data. | Exchange product pages describe paid historical products and extensive history; terms and access vary by product. | Contract-level data require roll and expiry handling; entitlement and licensing are product-specific. **Grade 1** for official product descriptions; independent data validation still necessary. |
| [Cboe U.S. options statistics](https://www.cboe.com/us/options/market_statistics/) | Exchange options volume, market statistics, and product data. | Public aggregated market statistics and separate paid data services. | Aggregate volumes are not option-level trade/quote history; coverage may be venue-specific or consolidated depending on product. **Grade 1** for exchange-published statistics. |

## Provider and endpoint leads

- [[London Strategic Edge]] — broad free-access claim, SDK documentation, and vendor terms; **Grade 5** for provider claims pending sample validation.
- [Alpha Vantage documentation](https://www.alphavantage.co/documentation/) — API catalog includes global stocks, FX, crypto, commodities, indicators, and fundamentals. Some endpoints are premium and usage/commercial terms vary; provider documentation is **Grade 5** for service claims.

Good for prototyping, not long-span candle history without another source. **Grade 5** for provider endpoint behavior.

## Choosing a source for a research question

1. Start with the **market variable and clock** required by the hypothesis; avoid selecting a dataset just because it is easy to query.
2. Prefer the original publisher for definitions, release dates, coverage, and corrections.
3. For prices and order flow, decide whether you need venue-specific events, consolidated trades/quotes, or reference bars. They answer different questions.
4. For fundamentals/macro, require point-in-time filing/release records and historical universe membership.
5. Confirm access and licensing *before* a large download or shared research use.
6. Take a small sample and validate against a second source where feasible.
7. Mark data with a grade, availability status, vintage/revision behavior, and known coverage limitations in [[Data provenance and point-in-time]].
