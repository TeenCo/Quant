# LSE Bounded Endpoint Sampling Script

Obsidian link target for [[sample_lse_dataset_endpoints.py]]. The helper makes opt-in small row queries (up to three rows per call) for schema inspection. It prompts the user to type `SAMPLE`, asks for the key with hidden input, saves a private local sample artifact, and never requests full history or launches an export job. See [[Sample LSE endpoint schemas]].
